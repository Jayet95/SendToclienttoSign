# טופס חותם — SendToClientToSign

אב-טיפוס למערכת שממלאת אוטומטית את **דוח ביצוע טיפולים** של אגף השיקום (משרד הביטחון)
מתוך קובץ ההפניה, ושולחת ללקוח **קישור חתימה דיגיטלית בוואטסאפ**.

נבנה עבור מכון פיזיותרפיה שמקבל הפניות ממשרד הביטחון וצריך להחתים מטופל על כל טיפול —
כשפר טיפול רק התאריך משתנה.

## הזרימה

1. **בחירת מטופל** — שני מסלולים:
   - **מטופל חדש** → העלאת ההפניה (PDF) של משרד הביטחון. המערכת קוראת את הקובץ ושולפת
     אוטומטית את פרטי המטופל, מס' ההפניה, סוג הטיפול, המק"ט והטלפון.
   - **מטופל קיים** → בחירה מרשימת מטופלים (עם היסטוריית טיפולים קודמת), או העלאת דוח קיים.
     למטופל קיים יש גם אפשרות **"הפניה חדשה למטופל זה"** (כשנגמרו הטיפולים והונפקה הפניה חדשה).
2. **מילוי אוטומטי** — נבנה דוח ביצוע טיפולים עם שורה חדשה שבה **תאריך היום כבר ממולא**.
3. **שליחה לחתימה** — כפתור שולח ללקוח הודעת וואטסאפ עם קישור לדף חתימה.
4. **חתימה** — הלקוח פותח את הקישור בנייד, חותם באצבע, והשורה בדוח מתעדכנת אוטומטית ל"חתום ✓".

## מצב נוכחי (אב-טיפוס)

- ✅ **קריאת ה-PDF אמיתית** — השדות המספריים (ת.ז, טלפון, מס' הפניה, מק"ט) נשלפים חיים מהקובץ
  שמעלים (pdf.js). לשדות בעברית יש כרגע ערכי בסיס מדויקים; חילוץ עברית מלא הוא שלב הבא.
- ⚠️ **שליחת הוואטסאפ מדומה** — לצורך ההדגמה. במערכת אמיתית מתחברים ל-`wa.me` / WhatsApp Business API.
- ⚠️ **החתימה** נשמרת כרגע רק בזיכרון הדף; בגרסה מלאה תיווצר PDF חתום שנשמר.

## ארכיטקטורה

| רכיב | טכנולוגיה | תפקיד |
|------|-----------|-------|
| **Frontend** | `index.html` (סטטי) על **Cloudflare Pages** | עמדת המטפלת — מילוי, עריכה, שליחה |
| **Backend** | **Cloudflare Worker** (`worker/`) | קישורי חתימה, שמירת חתימה, שליחת וואטסאפ |
| **אחסון** | KV (כרגע) → מומלץ **D1** לרשומות | סשני חתימה + רשומות מטופלים |

הפרונטאנד רץ היום כדמו עצמאי; חיבורו ל-Worker הוא הצעד הבא. פרטי ה-Worker: [`worker/README.md`](worker/README.md).

## הרצה

Frontend — קובץ HTML יחיד, ללא תלויות בנייה:

```bash
python -m http.server 8000
# ואז http://localhost:8000
```

Backend:

```bash
cd worker && npx wrangler dev
```
